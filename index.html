Formulaires SNEL (reproduction)

Reconstitutions à partir des scans du dossier Snel/image — HTML + CSS. Logo officiel : snel-logo.png (à côté des fichiers HTML).

Versions affiche (structure identique au papier, non remplissable à l’écran) :

  • Fiche mouvement compteur (portrait A4)
  • Fiche MVT clientèle BT — paysage A4
  • Police d'abonnement

Versions saisie (cases une lettre/chiffre, lignes pointillées et zones texte remplissables ; impression conserve la saisie) :

  • Fiche mouvement compteur — saisie
  • Fiche MVT clientèle BT — saisie (paysage)
  • Police d'abonnement — saisie

Versions saisie + QR (identiques aux saisie, avec code QR en haut à droite sur la feuille ; nécessite une connexion pour charger la librairie QR depuis le CDN) :

  • Fiche mouvement compteur — saisie + QR
  • Fiche MVT clientèle BT — saisie + QR (paysage)
  • Police d'abonnement — saisie + QR
Note : le logo est le fichier snel-logo.png. Les versions saisie chargent snel-forms-editable.css et snel-forms-editable.js ; les versions saisie + QR ajoutent snel-forms-qr.css, snel-forms-qr.js et la librairie qrcodejs (CDN). Par défaut le QR encode l’URL de la page ; pour un texte fixe, définir data-qr-text="…" sur <body>. La saisie n’est pas enregistrée sur disque. Pour usage officiel, se référer aux modèles SNEL.
